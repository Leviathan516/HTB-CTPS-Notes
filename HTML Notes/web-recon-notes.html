Virtual Host Enumeration KEY TECHNIQUE

One IP can serve many sites — gobuster probes the Host: header to find hidden vhosts the server responds to differently.

gobuster vhost
$ gobuster vhost \
-u http://inlanefreight.htb:PORT \
-w /usr/share/seclists/Discovery/DNS/subdomains-top1million-110000.txt \
--append-domain
⚠ Always add discovered vhosts to /etc/hosts
echo "IP vhost.domain.htb" | sudo tee -a /etc/hosts
✓
vhost prefixed "web" on practice target?
web17611.inlanefreight.htb

03
Fingerprinting
Banner Grabbing
$ curl -I http://target.com
# Look for: Server header

The Server: header reveals software + version. Follow redirects with -L or repeat on each redirect URL.

WhatWeb
$ whatweb http://app.target.local/

Identifies CMS, frameworks, server OS, cookies, jQuery versions, and more from a single request.

WAF Detection — wafw00f
$ wafw00f inlanefreight.com

Detected Wordfence (Defiant) WAF on inlanefreight.com. Know this before probing further — it may block scans.

Nikto — Vuln Scan
$ nikto -h inlanefreight.com -Tuning b
# -Tuning b = software ID only

Surfaces outdated software, missing headers, WordPress installs, exposed files like license.txt.

04
Crawling
Always Check First QUICK WINS
robots.txt
$ curl http://target/robots.txt
# Disallow entries = hidden paths!
sitemap.xml
$ curl http://target/sitemap.xml
# Full site structure
💡 The robots.txt Trap
Developers add paths to Disallow: to hide them from Google — which tells attackers exactly where to look. It's security through obscurity that actively helps recon.
ReconSpider (Scrapy-based) TOOL
1
Set up virtual environment
$ python3 -m venv myenv
$ source myenv/bin/activate
(myenv) $ pip3 install scrapy
2
Add target to /etc/hosts first!
$ echo "IP dev.web1337.inlanefreight.htb" | sudo tee -a /etc/hosts
3
Run crawler
(myenv) $ python3 ReconSpider.py http://dev.web1337.inlanefreight.htb:PORT
4
Read results
$ cat results.json | jq
# Extracts: emails, links, JS files, comments, forms, images
⚠ Sub-vhosts can have their own sub-vhosts!
After finding web1337.inlanefreight.htb, run gobuster vhost again targeting that subdomain to find dev.web1337.inlanefreight.htb. Don't stop at one level.
