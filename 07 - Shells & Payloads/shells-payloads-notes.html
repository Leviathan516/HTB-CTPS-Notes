Shells & Payloads

Gaining and upgrading shell access across Windows and Linux — bind vs reverse, staged vs stageless, web shells, and the three-host skills assessment pivot from a dual-homed foothold.
01 Shell Types
Reverse Shell most common

Target connects back to the attacker's listener. Best when the target can reach out but inbound is filtered. You start the listener first, then trigger the payload.

Attacker listener
$ nc -lvnp 443
Bind Shell target-side listener

Target opens a port and waits; the attacker connects in. Useful when the target can't initiate outbound — or, as in this assessment, when picking a callback IP on a multi-homed pivot is awkward.

Attacker connects in
$ nc -nv 172.16.1.12 4444
Direction = firewall strategy
Reverse shells beat outbound-permissive firewalls; bind shells beat inbound-permissive ones. Egress filtering on common ports (80/443) is the usual reason a reverse shell on 4444 silently fails.

03 Interactive Shell Upgrades

Landed in a limited / jail shell? Spawn a real TTY using whatever interpreter is installed linux

# classic — python TTY python3 -c 'import pty; pty.spawn("/bin/bash")' # no python? fall through to whatever exists /bin/sh -i perl -e 'exec "/bin/sh";' awk 'BEGIN {system("/bin/sh")}' find . -exec /bin/sh \; -quit vim -c ':!/bin/sh' # once stable, check leverage sudo -l ls -la /path/to/binary
Then stabilize
After spawning bash: Ctrl-Z → stty raw -echo; fg → export TERM=xterm for arrow keys, tab-completion, and a working sudo -l.
04 Infiltrating Windows
Common Windows vectors windows

MS17-010 (EternalBlue) SMBv1 pool corruption, vulnerable service exploitation via Metasploit, and payload delivery + remote execution. The ms17_010_command aux module can read files without a full session by abusing the write-what-where primitive.

05 Infiltrating Linux
Common Linux vectors linux

Vulnerable web apps / CMS plugins, misconfigured services, and known-CVE exploitation. Web-app footholds often drop a scripting-language web shell (PHP/JSP) that you then upgrade to an interactive TTY.

06 Web Shells
Laudanum

Pre-built shells in many languages. Edit the allowedIps[] allowlist to your source IP or it returns access-denied.

Antak (.aspx)

PowerShell-based ASPX web shell from Nishang — for IIS / .NET targets.

PHP one-liners

<?php system($_GET['c']); ?> — minimal, useful when an upload filter is weak.

Laudanum allowlist gotcha
Both the JSP and ASPX templates ship with a hardcoded IP allowlist. On a pivot, that must be the foothold's internal interface IP — the address the target actually sees the request coming from — not your VPN address.

Why bind, not reverse?
This module uses a bind payload — the foothold dials the target instead of waiting for a callback, neatly sidestepping the multi-homed callback-IP problem. The flag name is a wink at exactly that.

07 Detection & Prevention
File uploads

Watch web-app logs for unexpected .war/.aspx/.php writes. Sandbox internet-facing apps; run AV on the web server itself.

Anomalous sessions

A heartbeat on port 4444 (Meterpreter default) in NetFlow is a classic IOC. Bind shells flip direction but still create host-to-host traffic that shouldn't exist.

Suspicious commands

Normal users rarely run whoami or net user. Command-line + PowerShell logging surfaces it fast.

MS17-010

Patch and disable SMBv1. Host hardening + segmentation stop lateral movement from a boundary host.

MITRE mapping
Initial Access (public-facing app) → Execution (uploaded payload) → Command & Control (established session). Baseline the network so deviations are loud.
